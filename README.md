# 🎮 Gaka

Projeto desenvolvido para apresentar uma loja virtual moderna de videogames, com visual responsivo, animações suaves e carrinho lateral interativo.

---

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- AOS Animate Library

---

## ✨ Funcionalidades

- Layout moderno e responsivo
- Catálogo de produtos
- Carrinho lateral funcional
- Overlay escurecendo o fundo
- Animações suaves
- Botão de finalizar compra
- Interface inspirada em e-commerce
